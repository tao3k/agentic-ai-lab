* Ownership

Inputs are call-bounded borrowed byte views.  Outputs are ABI-owned byte buffers
released through =agentic_ai_lab_runtime_v0_owned_bytes_release=.  No pointer is a
resource handle and no Scheme heap address crosses the public boundary.
