#+TITLE: Reuse the image-reading mechanism: hybrid runtime allocation
#+LANGUAGE: en

The whole-scene SVG experiment described later in this history is rejected as
reuse evidence. The current teaching case no longer selects that SVG or declares
handmade regions, solver options, direction or important routes. It supplies
source-qualified meanings and local object/state imagery to the Module's
composition rules. The historical output below is not a qualification of the
new rule-driven renderer. See =../policy-generation/README.org= for the new
native-rendering reuse check and actual image feedback.

* Existing design and new reader context

This example uses the existing
[[file:../../../../docs/10-19-design/10.06-poo-module-system/agentic-ai-context/28-hybrid-runtime.org][28-hybrid-runtime.org]] and
[[file:../../../../docs/10-19-design/10.06-poo-module-system/agentic-ai-context/28-hybrid-allocation.sysml][28-hybrid-allocation.sysml]]. Neither source is rewritten for rendering. The
small =view.sysml= selects the native =HybridNode= allocation. The SDK supplies
30 source occurrences and their ownership. The native provenance selection omits
unneeded fields and one intermediate VM boundary; its source ancestry remains
captured, and ASCENT derives the nearest visible owner.

The new reader asks about I/O versus semantic authority, originals versus
returned results, independent Session completion and the three explicitly false
deployment flags. All ten original facet requirements are retained. The mechanism revision adds
visible Context-state and independent terminal-authority requirements.
The drawing describes the selected design; no new runtime qualification was run.

* What is reusable

The new example owns POO =case.ss/teaching.ss/readings.ss=, a native view and SVG assets.
It has no TypeScript layout, pixel positions or connection routes. The existing
SDK =composeDiagram/graphFromModel= and ELK calculate all placement. The generic
=reuse.ts/reuse.ss= adapter contains no source-specific name, layout or icon
dispatch branch. Native layout options are POO data and are inherited uniformly
by visible compound nodes.

=modules/d2/ascent-scene.ss= relates reader needs to source occurrences and
model choices. It preserves visible ancestry, exposes missing choices and refuses
unknown references/cyclic ownership. =plan/author/inspection= are the same public
Module operations used by the time-window example. Their answer coverage now
joins actual grounded facets individually, rather than requiring a manually
positive representation-review record.

The initial structural projection used small role glyphs. Those were rejected
as insufficient teaching images. The current =TeachingItems= instead depict
object/state contrasts: an arriving envelope, conditional checks, pinned homes,
proposal output, detached byte copies, retained originals, separate ledger
states and three visibly different implementation gaps. Each selected depiction
retains its rationale and located source quotation in the generated report.

* Connected mechanism revision

The replacement preserves the original ten facets and adds explicit views of
Context v0, a possible Context v1 and independent Session terminal authority.
Candidate R, its copied handoff, original evidence and the current source/policy
cut now meet at one checker. The admitted branch adds R and its relationships;
the not-admitted branch leaves the same Context unchanged. Optional computation
feeds a proposal back to that check. Session arrival observation and Context
admission are distinguished from the Session owner's independent final decision.

=TeachingMechanism= contains source-qualified links, required relations and
requested causal traces. Deleting a required link cannot be compensated by a
caption. Non-propagating constraints cannot be counted as causal paths. This is
an explanatory read model; its arrows are not an executor's next-step policy.
=modules/d2= owns that inference. The reusable compositor owns no design names,
coordinates or routes; it calls the existing SDK and ELK.

The first connected export was rejected by the unchanged font gate: its actual
horizontal layout shrank text to about 7px. The actual rejected PNG was viewed
and its failure returned to Context. A diagnostic vertical reflow restored
legibility but still wasted space because caveats were ranked as stages. The
model therefore attached each caveat to the affected ingress, foreign boundary
or fixed-owner check. These observations concern the physical picture, not a
request-count definition of successful teaching.

The final reading order starts with the same example result R. Explicit links
carry its separate copy to the check, while original evidence and the current
Context provide the reasons for that check. Two conditional relations show what
stays the same and what can change: A/B/C remain in v0, or the new v1 also contains
R and its relationships. These are illustrative possible states, not a recorded
production execution or an unconditional state-machine schedule.

The Session has its own branch: R's arrival is only an observation; its owner
records the final outcome independently. A crossed no-effect statement on the
changed Context prevents reading admission as task completion. The three
unimplemented deployment qualifications remain attached to their affected sites.
Plain-language labels replace specialist terms such as source/policy cut,
terminal and pre-setup heap; exact Org/SysML quotations remain in the report.

During actual image inspection the model reopened otherwise covered questions
for an unclear entry point and unexplained vocabulary. Those observations, the
rejected wide mechanism, and the overly tall reflow remain image-bound in
=readings.ss=. The engine's inventory coverage is never presented as evidence
that an elementary-school student understood the picture.
