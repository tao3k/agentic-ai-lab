The installed Gerbil =std/os/signal-handler= interface is imported
by Yuanxu's Ops progress module. It brings the native logging
facade into these children even when they never register an
execution owner. In the fixed Gerbil source the signal-handler
implementation is delayed until registration. A focused candidate
moves the existing cancellation extent to the Ops execution
module, where resource owners can still use it. The progress
module keeps its counters and output protocol. The Lean
projection separates registration from progress and preserves
the register/acquire/body/release/unregister order. The existing
Quint TestSourceAdmission safety simulation passed and its
hard-stop variant violated =FailureCleanup=. These models do
not establish native signal delivery or teardown latency.
