* B2 implementation and delivery gate

The Library exposes named acyclic support inventories, including claims with
zero supports. Alternative supports project to the original conclusion identity
before the existing reverse scheduler computes affected downstream conclusions.
Complete declared inventories produce unsupported after the last support is
withdrawn; partial inventories preserve unknown. Unsupported is support
applicability, not logical refutation or proof admission.

MRR preserves original Fact/Derivation identities and output content, admits
named inventories and calls the Library's reverse and claim-selection operations.
The Rust consumer emits original =claims.ss= revision oracles; the installed
Python Library replays them against the same native artifact. Acceptance covers
two supports to one to none, downstream propagation, zero-support parents,
late correction, conflict, historical cuts and host policy expiry.

Claim selection is relative to the caller-declared journal cut and inventory.
A retained native binding from a different cut yields stale Context and unknown.
This is a native cut-binding check, distinct from the existing MRR admitted
agentic Context family's source/catalog controls. Only the registered policy
Host supplies policy and evaluation time. No authoritative current-source
registry, complete provenance inventory or effect permission is established;
proof/source/selection/effect/durable admission flags remain false.

The shared package-managed entry is
=gerbil env bash runtime/tools/qualify-library.sh POO_PACKAGE OUTPUT= in MRR.
Cargo validates the locked graph, builds and lints; the existing bounded native
recipe performs execution. CI keys Cargo's dependency/build cache by SDK/toolchain and immutable package
locks; Cargo owns source invalidation. The native AOT artifact is freshly built
and execution always runs. CI calls
that same entry, without another installer or job. Gerbil dependencies continue
through =gerbil deps=, Rust through rustup/Cargo and Python through uv. Builds
stay outside execution deadlines; cache hits never replace fresh execution.
B2 delivery requires the new producer oracle, Python replay with no skips and
all checks on the delivered head. General Quint/native refinement remains B4.
