#+TITLE: Registered Host policy control through C/Python/Rust ABI v1

* Qualified boundary

The dedicated C Host entry registers native POO policy/observed-time snapshots.
The read-only support guard consumes the registered snapshot using expected
generation and policy digest. C rejects ordinary =$host.= calls with status 3
before dispatch; Python also rejects them before enqueueing. The descriptor
advertises the guard only. No policy/clock replacement or admission flags are
accepted in ordinary guard requests. The opaque native registry validates all
updates before mutation. Actual tests retain the previous guard result after
rejected clock/generation rollback, revision conflict and malformed refreshes.

The policy's [start,end) boundaries are exercised before start, at start and at
end. Old generations reject; stale digests return stale-policy. Actual Rust and
Python replay the same inert =typed-policy.ss= fixture against the same fresh
semantic AOT library and produce identical registration and expiry results.
The fixture is a policy projection, not a proof or authenticated provider claim.

* Executed gates

=qualification.ss= records 16 exact source hashes, the fresh artifact digest,
three compiler-generated SCM hashes, owner revisions, counts and gate durations.
=native-artifact.ss= is the full compiler closure manifest. Its module hashes
refer to generated SCM, not original .ss sources. The retained SCM bytes match
those manifest hashes. Gerbil is v0.19; transport and all schemas remain v1.

The build used =bindings/runtime-c/tools/build-semantic.py --output
/private/tmp/poo-host-policy-v1-aot/libsemantic-v1.dylib= in the qualified private
SDK. The fresh library SHA256 is
=96e4562c34ec9e44bbef56a4c54eb0558773392c563324125273832992f352a3=.
The Python CFFI shim was rebuilt from the current sources with an existing
cached setuptools build dependency, without changing the runtime dependency set.

All tests used the existing =packages/python-runtime/tools/watch.py= with
five seconds without actual command output and an outer 45-second timeout.
Actual native completion and completed parser/test work provide progress.
No fake heartbeat, relaxed deadline or retry inside the harness was introduced.
