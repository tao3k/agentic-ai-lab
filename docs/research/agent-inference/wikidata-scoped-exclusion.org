These are *selected* claims, not an exhaustive extraction of =P131=,

entity versions, not one transactional Wikidata dump. The =city=
rows =Q100/Q62/Q18013= and =target= row =Q30= are explicit query
scope, not claimed Wikidata statements. Results mean exact closure over
this local finite extract. They do not assert that absent Wikidata
statements or missing real-world facts are false.

* Structured question and independent oracle

The structured question is: which selected cities are in the United
States either (a) through an administrative chain *provided they are
not a selected state capital*, or (b) through a direct country claim?
The exclusion applies only to branch (a). An ordinary set walk over
the source pairs is the independent test oracle; it does not call the
relational compiler or evaluator.

| Observation | Exact finite result |
|-------------+---------------------|
| =viaAdmin(city,Q30)= after transitive =P131= | =Q100, Q62, Q18013= |
| =excluded(city)= from the two selected =P36= facts | =Q100, Q18013= |
| Scoped answer, both branches | =Q100, Q62, Q18013= |
| Wrong control: exclude after branch union | =Q62= |
| Generation 2: withdraw only =P17(Q100,Q30)= | =Q62, Q18013= |

The test checks candidate completion, full rows, intermediate
relations, stratified proof verification, source-generation mismatch,
and retained Scheme Session replacement. The old receipt and old
Session result remain tied to generation 1. The withdrawn row in
generation 2 is a *counterfactual local source change*, not an edit to
Wikidata or a claim that Wikidata removed the statement.

* What this does not measure

This is an executor/semantics discriminator, with no model proposal or
raw model response. The next model study must submit a request once,
preserve its raw response, then compare its admitted program and exact
rows with this gold structured request. A gold executor result cannot
by itself establish natural-language intent fidelity. The tiny extract
does not qualify [[https://proceedings.mlr.press/v306/miao26e.html][MatLogic]]'s reported benchmark, a population
estimate, or an MRR publication path.
