* User Interface Contribution Library

This directory models the downstream surface that users and agents read before writing Agentic AI Lab configuration. Stable policy objects live in =profiles/=, and reusable workflow compositions live in =scenarios/<name>/scenario.ss=.

* Reusable Profiles

- =profiles/langchain.ss=: linear chain profile slots for memory, prompt, model, parser, and no-tool policy.
- =profiles/langgraph.ss=: guarded graph profile slots for session, state, router, agent/tool nodes, bounded loop, and runtime handoff.
- =profiles/crewai.ss=: CrewAI-style profile slots for agents, tasks, crews, processes, flow state/router/persist, guardrails, human input, observability, and runtime handoff.
- =profiles/tool-calling.ss=: framework-neutral tool calling profile slots for tool request, schema, permission, sandbox scope, cooldown, runtime binding, receipts, and observability.

* Reusable Scenarios

- =scenarios/langchain/scenario.ss=: LangChain-style composition.
- =scenarios/langgraph/scenario.ss=: LangGraph-style guarded state graph composition.
- =scenarios/crewai/scenario.ss=: CrewAI-style crew/flow composition that reuses profile slots instead of cloning CrewAI's Python runtime surface.
- =scenarios/tool-calling-agent-loop/scenario.ss=: framework-neutral tool calling control-plane composition for agent loop/tool/state runtime handoff.

* Rule

Object-level Case extension uses native =gerbil-poo= noun slots:

#+begin_src scheme
(.def OntologyCase
  (events ? (.o)))

(.def (PrescriptionCase @ OntologyCase)
  (events =>.+
    (.o prescription: PrescriptionEvent)))

(.def (ReviewedPrescriptionCase @ PrescriptionCase)
  (events =>.+
    (.o prescription: ReviewedPrescriptionEvent
        review: ClinicalReviewEvent)))
#+end_src

The root config only composes prepared Profiles and Standards:

#+begin_src scheme
(user-composition my-composition
  (compose profiles
    (use-module crewai production)))
#+end_src

Do not add a parallel JSON/alist language, action evaluator, stage grammar, or
framework-specific DSL for these scenarios.
