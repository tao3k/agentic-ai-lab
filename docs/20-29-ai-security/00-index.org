* Purpose

This Org-first family owns AI-security research, architecture semantics, and
enterprise security architecture packages built with the Agentic AI Lab engine.

Agentic AI Lab itself remains the general POO-native architecture-semantics
composition engine.  Documents in this family describe security architectures
that the engine may compose; they do not redefine the engine or widen its
public API.

* Ownership boundary

This family owns:

- external AI-security architecture observations and crosswalks;
- semantic catalogs derived from papers, standards, incidents, blogs, and
  GitHub issues;
- composable enterprise AI-security architecture packages and profiles;
- cross-architecture mapping, conflict, refinement, and unknown semantics;
- security-specific proof and runtime projection requirements.

This family does not own:

- POO module-system implementation;
- public =compose=, =profiles=, =use-module=, or =use-composition= APIs;
- policy composition proofs;
- Lean proof infrastructure;
- runtime coordinator effects;
- vendor data, model, IAM, SOC, or governance products.

Those remain with their existing owners and are referenced through explicit
projection contracts.

** 20.07 Embodied AI Security System Engineering Design Proposition

- File: [[file:20.07-embodied-ai-security-system-engineering-design-proposition.org][20.07-embodied-ai-security-system-engineering-design-proposition.org]]
