# Library cross-path Fact and proof-fragment pilot

This is a bounded consumer test of `candidate/evidence-store.ss`, not a Library search API. The Library returns verified ground Facts, ancestor-closed proof fragments, and finite-absence partitions. The consumer owns the objective, branch bookkeeping and budget; an independent raw-source BFS and exhaustive enumeration judge feasibility and quality. No Agentic AI Lab workflow dependency is added.

Two immutable tasks contain eight choice stages, shared directed-path prerequisites, cost/risk constraints and pair bonuses. Each treatment starts with the same feasible solution of value 79; exhaustive optima are 289 and 304. Every model action extends one supplied parent by one child. Parent options remain available until tried. Invalid choices and branches remain recorded. Baseline receives the raw source; Fact-only adds verified branch-relevant ground outcomes; Scheme adds the corresponding shared support DAG and Library finite-absence partition. Scheme does not rank choices or reveal the optimum. This combined treatment does not isolate proof visibility from pruning.

The plan freezes the tasks, independent judge implementation, source/build hashes, question, tool schema and annotation rules before calls. Both tasks use a 65,536-token ceiling per treatment trajectory, counting every request input and all returned output, including reasoning and cached-input subsets. The single-response cap is 8,192 tokens, with at most 24 calls. Reservation or call-limit stops are censored; unused budget is not savings. Compare only jointly reached 8,192/16,384/24,576/32,768/49,152/65,536-token checkpoints, using actions completed by each checkpoint.

Annotate original returned thinking with exact quotes and spans, keeping derive, reuse, mention, conditional recheck and uncertainty separate. A qualified derivation requires an independently true atom and an explicit supported edge/path chain or ready conjunction. Repeating a qualified conclusion is a repeated Fact derivation; repeating its same ordered premises is separately an exact derivation repeat. Different search parents do not reset prior source conclusions. A single reference to an existing path is reuse, not derivation. Invalid, false, unsupported or unanchored labels remain rejected; missing measurements remain unknown. Annotation is blind to treatment names, score and budget, but text can disclose evidence. Extraction completeness and inter-rater agreement are unvalidated, so measured episodes are observed lower bounds. Annotation costs are retained separately.

The dynamic consumer reloads the actual `evidence-store.o1` module against a prelinked matching dependency closure and verifies changed contract identity. EOF drives normal cleanup within the unchanged five-second deadline. Full `gxi` loading was sampled in Gambit `___cleanup_dyn_module` / `dlclose` / macOS dyld unload notifications and remains a recorded external runtime failure; this pilot does not claim to repair that global runtime path. No immediate exit or forced kill is counted as a clean shutdown.

All raw requests, responses, thinking, incorrect choices, truncations, unknown usage, shutdown failures, rejected annotations and historical failures are retained. One trajectory per arm/task supports only a small exploratory comparison, not a general causal or performance claim.
