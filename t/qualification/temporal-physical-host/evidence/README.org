#+title: Physical Temporal evidence retention

Raw execution logs are local or CI artifacts and are not stored in Git.
The historical structured summaries preserve outcomes and source identities.
A new source or dependency cut requires a fresh executable gate; an old hash
or passing line cannot establish current runtime behavior.
