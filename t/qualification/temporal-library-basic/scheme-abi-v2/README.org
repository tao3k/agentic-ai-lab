* Failed attempts and repairs

The first installed v2 run had 91 passes and 9 failures. Two failures lacked the
control-lane artifact environment; seven exposed a remaining JSON encoder in
TemporalPublicationStore's trusted host callback. The callback now uses Scheme
wire, and the final installed-wheel run supplied both real native artifacts.
The first v2 native artifact was

The numeric grammar now compiles its regexp once. The final artifact rebuilt
that module and the semantic root against the isolated prefix from the complete
build, then re-linked the compiler-resolved closure. This is a local incremental
build receipt, not a reproducible-build or universal speedup claim.

After measurement, the external benchmark test moved into its own opt-in
directory so ordinary unit discovery cannot run it without installed artifacts.
Its measured source is retained in [[file:cold-benchmark-source.ss][the source snapshot]]; the receipt keeps its
original path/hash. No timing result is changed by that relocation.

The cold benchmark failed its original 900ms p95 gate. It was not retried or
relabelled as a pass. A subsequent host observation reported load averages
181.16 / 156.58 / 124.16; this is context, not proof of a sole cause. A qualified
uncontended run or a separately justified production-residency benchmark remains
necessary for a performance claim. ASP memory statistics here describe the Scheme
harness, not child Rust/native peak memory.

Installed wheel tests use an external pytest configuration so repository
pythonpath settings cannot substitute source files for the installed consumer.
Rust tests and wheel tests ran with a five-second genuine-output watchdog.
Scheme harness bootstrap uses the heap-fenced Justfile entrypoints; no claim is
made that harness compilation/initialization completed within five seconds.
