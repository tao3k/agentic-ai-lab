# Complete-thinking Library diagnostic — prospective protocol

The frozen tasks, question, branch constraints, common nonoptimal feasible starts,
independent exhaustive grader and per-cell 32,768 input-plus-all-output token
ceiling are unchanged from branch-entry. Model alias deepseek-flash and low
reasoning stay fixed. Baseline, Fact and Scheme use the same common submission
tool with automatic choice. No anti-repetition or shortening instruction is added.

The 2,048-token checkpoint is removed. Each first call receives the remaining
cell allocation after a conservative input reservation. A response is a completed
thinking observation only when the provider reports completed. An incomplete
response is preserved as a censored failure and never converted into an answer
by switching thinking off. A completed plain response may use the existing bounded
non-thinking structured transport only if all its replay input plus output fit
inside the same ceiling. Output limits are budget-derived, not timeout widening.

The existing public Python binding projects the already verified native packet
into lossless named columns. Common conclusion fields and node field names appear
once, with all scope digests, statuses, handles, roots, labels and ancestors
preserved. Expansion must equal the complete native observation. Fact and Scheme
share exactly the same conclusions; Scheme adds checked named support. Evidence
arrives before the first model call of every sibling branch. No Python inference,
search framework, authority admission or new version module is introduced.

The frozen literal annotation remains an independently checked measurement.
A supplementary blind semantic model pass labels every numbered line as premise
use, path derivation, absence argument, optimization, other or unresolved. Atomic
inference proposals include exact quotes, literal endpoints and explicitly stated
ordered premises; existing local truth/span validation admits or rejects them.
Supplied result use is separated from rederivation. Line classifications are model
proposals, not verified semantics. The same model is a correlated annotator, not an
independent rater. Missing lines, truncated annotations, unverified premises and
call-bound exclusions remain failures/unreviewed records. No grades, gold answers,
arm names or costs are exported to the annotator or returned to the solver.

Maximum new calls: 18 solver plus 10 semantic annotations. Together with the 44
retained earlier attempts this stays within the original 73-call authorization.
Annotation costs are reported separately and cannot fund solver gains. Cached and
replayed input counts in full. Unknown usage is not zero cost; unused budget is not
savings. All semantic, transport, timeout, infeasible and budget failures remain.

Provider output bound definition: [DeepSeek Responses API](https://api-docs.deepseek.com/api/create-response/).
