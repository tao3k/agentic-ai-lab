* Scope: Closing the Last Two Open Gaps in the 2025–2026 Literature

[[file:50-literature-frontier-detour-confinement-and-causal-audit.org][Slice 50]] absorbed APPA confined-detour taint isolation, NeuroTaint offline
causal auditing, and deterministic stall advisories. Deepening our literature
survey reveals **two remaining structural gaps** actively studied in 2025–2026
systems and security research that directly affect long-horizon Shared Org
Context:

1. **Persistent Memory Poisoning & Experience Imitation Hijacking**
   (*AgentPoison*, NeurIPS 2024; *MINJA*, 2025, >95% query-only memory
   injection; *MemoryGraft*, Dec 2025, persistent compromise via poisoned
   "successful" procedural experience templates):
   - Even with [[file:49-scoped-detour-funflow-concurrent-shared-context.org][Slice 49]]'s =Extend-Never-Overwrite= per-=:ID:= ownership, an
     agent exposed to an untrusted artifact (e.g., a malicious README) can
     legitimately append a *new* child subtree =:ID: Y= claiming a "successful
     procedural recipe". If future sessions retrieve and imitate =Y=, the
     compromise persists indefinitely across sessions without overwriting any
     existing node.
   - **Resolution — Quarantine-Before-Recall & Typed Memory Contracts**: Every
     memory or experience candidate originating from an untrusted or
     taint-exposed turn enters a =quarantined= staging tier that is **strictly
     excluded from production recall**. Self-claimed success from an untrusted
     origin can never auto-promote; promotion to =recallable= requires a typed
     =MemoryContract= check plus non-self =EndorsementReceipt= and zero open
     =defeat-conditions=.
2. **KV-Cache Radix Fracturing, Request-Order Sensitivity & Context Rot**
   (*RadixAttention / SGLang*; *CacheBlend*; *KVCOMM / TokenDance*; *Request
   Order Matters: Cache-History Sensitivity in Selective KV-Cache Reuse for
   Rolling Agents*, 2026):
   - Deleting, compacting, or reordering an early summary block inside a rolling
     agent prompt shifts downstream tokens, fracturing the KV radix tree
     (observed hit-rate collapse from 99.6% down to 10.1%), triggering
     multi-second prefill stalls, and inducing order-dependent context rot.
   - [[file:35-org-context-modules.org][Slice 35]] already states that *final prompt order is a separate, explicit
     serialization policy, not inheritance order*. Here we formalize a
     **Two-Zone Prefix-Stable Serialization Law**:
     - *Frozen Canonical Prefix Zone*: immutable policy/goal spine + sealed
       =L0/L1= skeleton serialized in canonical =(epoch, nodeId)= order (never
       mutated mid-epoch and invariant to peer arrival order).
     - *Dynamic Suffix Zone*: active =L2/L3= drill-downs, =Scoped Detours=, and
       live peer =:ID:= extensions appended strictly *after* the frozen prefix
       boundary so opening/folding detours preserves 100% token-identical KV
       prefix alignment.
