* Judgment

The first integration with a training framework can consume *discrete*
checked facts, counterexamples or evaluation records.  It need not sit
inside backpropagation.  If the goal becomes a differentiable operator,
that is a separate language and algorithm research program: define a
weighted fact algebra, prove the forward and backward contracts, and
compare gradients with an independent reference.  Keep both options
visible without calling a data-export adapter a differentiable layer.
