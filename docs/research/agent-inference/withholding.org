* Scheme architecture decision

[[file:../../features/withholding/acceptance.org][Finite withholding]] extends the existing candidate snapshot/feedback path. The caller
supplies groundings as =(head-atom body-atoms)=. The builder checks source
membership and tuple schema, collects every head and every protected body atom,
rejects their intersection, then publishes a copied higher-generation snapshot.
It preserves the original snapshot and its full reference rows. Existing
reasoning execution and independently verified finite evidence recover a withheld
answer under an explicitly supplied composition rule. A direct-lookup proposal
loses that answer; candidate execution feedback complete row feedback reports it as missing.

This is a deterministic dataset-cut mechanism. It does not validate that the
provided body entails the head. Caller-supplied groundings require separately
admitted rule semantics before a reasoning claim. The finite family control is
hand-written, not an AMIE3 output or real-KG extraction. Lean describes exact
set removal/protection; Quint checks whole-batch publication and rejected faults.
Native source/schema/hash correspondence remains an executable-test boundary.

* Remaining experiment

Running released mined-rule groundings, real KG versions, answer extraction,
retrieval/ranking metrics and model-generated language remains open. Confidence
metadata never changes Scheme source membership or promotes a proposed rule
to an authoritative fact. Natural-language fidelity and external source authority
remain separate from finite execution agreement.
