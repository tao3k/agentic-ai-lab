* Objective and protocol

Validate native trajectory accounting and current-source Evidence DAG reuse, then measure actual provider thinking until the first independently verified complete answer. Test exact-repeat retrieval and changed-query intermediate reuse separately. No output-byte proxy, reconstructed hidden reasoning, remote CI or estimated dollar saving is used.

12 independent task instances were frozen before calls: 8 single-query tasks and 4 two-query bundles. This is 16 distinct query obligations and 24 condition task trajectories. Each bundle succeeds only when both query obligations pass. Both conditions preserve actual model history. Conditions alternate order. Maximum three attempts per query, deepseek-flash high reasoning, 131072 output-token cap. Actual request/response usage and visible answers are retained. Provider output has no server-side JSON schema constraint; explanatory prose and Markdown surrounding a final answer object are accepted.

All 16 distinct query obligations were checked by a separately implemented Python closure/join oracle and actual Scheme before paid calls. Complete answer relations are graded as sets, rather than selected examples. A scalar failure triggers repair; applicable Scheme evidence is exposed only in the evidence condition. Failure and repair calls belong to the first-success prefix. Unknown usage makes that prefix incomplete. Later repeats are post-success work, and source replacement creates a new generation. Provider output_tokens already includes reasoning_tokens.

* Task provenance and complexity

The design is informed by [[https://arxiv.org/abs/2609.37233][DatalogBench]] execution and oracle-mutation methodology, [[https://arxiv.org/abs/2303.11366][Reflexion]] feedback across trials, and [[https://arxiv.org/abs/2506.14852][test-time plan caching]] reuse. These are generated experiments, not official benchmark scores or reproductions. Fresh entities and seeded graph structures prevent exact answer lookup for these instances; training exclusion is not established, and the underlying algorithms may be familiar to the model.

Tasks contain 36–48 nodes, 109–145 edges, recursive fixed points, cycles, multi-relation joins and scoped exclusions. Taint tasks test sanitizer boundaries; conjunctive tasks require both prerequisites rather than either; bidirectional tasks require forward and reverse closures. Second queries add new compositions over unchanged sources. Their retained reach/back packet never includes the second answer. One transfer first query has an empty answer and is explicitly retained; zero output cardinality does not establish equal difficulty to nonempty queries.

* Request, failure and accounting audit

Across all 12 task instances, cumulative thinking to first complete correct answer is 128045 baseline versus 120851 native, an observed 5.62% reduction. Including the eight specified exact repeats makes the mixed workload 191869 versus 120851, an observed 37.01% reduction. These aggregates mix distinct task and reuse opportunities and are not a universal saving estimate.

Actual provider requests: 40; provider errors: 0; non-completed responses: 0; complete reported thinking usage: True. Total actual thinking across both conditions and repeats: 312720; input: 169602; output including thinking: 317330. These are experiment expenditure totals, not the matched reduction denominator. The two conditions are experimental alternatives; their costs are not both needed to run the deployed reuse policy.

Censored/failed trajectories remain in record files and overall denominators. No unknown usage is imputed as zero. Accuracy is independently checked full-set equality. Repair thinking counts actual calls linked to an earlier failed verdict. No simulated token value is mixed with provider usage. There is no dollar estimate because this study qualifies thinking consumption, not provider invoice pricing.

* Native and formal qualification

Five direct Scheme ledger cases pass. Actual ABI and compiled API each pass three Trajectory and nine Evidence DAG cases (24 binding integration cases). Four experiment-intent tests pass. Lean compiles the temporal prefix, preceding failure/repair cost, invalidation and unknown-usage statements. The healthy Quint model passes 10,000 sampled traces of at most 30 steps at seed 13; four intentionally weakened variants each produce counterexamples. This is bounded simulation, not exhaustive model checking or universal source refinement.

The controlled correction regression charges 80 failure + 30 repair = 110 before first success, and leaves a later 50 outside that prefix. Invalid event observations are atomic; stale source/reference observations and invalid repair links are rejected. These are executable mechanism controls, not real model failures. Natural correction effectiveness remains unmeasured when the real model succeeds without repair.

ABI, packaged native and API producer inputs share canonical source/build identity. The API bundled library has a distinct hash after its required Darwin install-name/ad-hoc signing transformation; that output and the CFFI extension are separately bound in the qualification receipt. Local qualification does not assert portable wheel or remote CI success.

* ASCENT design conclusion

Evidence DAG owns prerequisite/component structure and applicability. Trajectory owns ordered observations, first-success cost and source-generation history. EvidenceChain connects them: actual native query results append evidence observations; a retained answer follows a checked path; replacement revokes references and opens a new cost epoch. Lean specifies why a final DAG cannot represent temporal cost, and Quint explores the lifecycle transitions. The model receives current applicable evidence through the host; it does not author trusted cost or correctness events.

The implementation now supports both exact-repeat call avoidance and independently observed next-query intermediate reuse. The data distinguish source validity, response quality, failure-repair accounting and thinking consumption. Remaining efficacy claims must be tested with larger, harder held-out instances, repeated paired samples and actual failures; the current small local study must not be generalized.
