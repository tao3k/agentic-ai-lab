* Question

Can a model read ordinary Gerbil Scheme programs and current ASCENT
module source, then predict one finite answer datum for each? This is a
source comprehension study across distinct Scheme tasks. An exact answer
shows success on that program and prompt; it cannot reveal the model's
internal reasoning or establish general Scheme competence.

* Fixed corpus

Each case receives one fresh model call. The outgoing message is the
literal source in the preview directory. For the last three cases it
includes the actual imported ASCENT module source followed by the calling
program. Expected output is generated by executing the calling program
with Gerbil at the pinned ASCENT head, saved separately, and never sent.

| Case | Question tested |
|------|-----------------|
| =control_pure= | Ordinary Scheme evaluation without ASCENT |
| =control_contract= | Explicit ASCENT API contract and row prediction |
| =withdrawal= | Source replacement and removal of old derived rows |
| =negation_count= | Stratified negation, guards, computation, and count |
| =module_fragment= | Public relational-fragment export and alias |
| =module_diagnostic= | Admission diagnostic code and source path |
| =receipt_boundary= | Finite/founded receipt scope before and after source change |

The =module_fragment= and =module_diagnostic= payloads include
=program/interface.ss=; =receipt_boundary= includes
=candidate/reasoning.ss=. The other four payloads contain their calling
scripts only. The questions cover different capabilities, so their scores
are reported by case as well as in aggregate. There is no repeated repair
loop or claim about an unobserved cognitive mechanism.

* Native answer and model rule

Run each program with the same committed checkouts and a 1 GiB Gerbil
heap fence. Preview generation uses at most two native processes at once.
The source, expected answer, pinned Git heads, and SHA256 hashes are
recorded in an external preview manifest. Live execution requires clean
checkouts and an exact match to that manifest and the Agentic AI Lab ASCENT pin.

Use =deepseek-flash= through the Responses API, non-thinking,
=temperature=0=, =max_output_tokens=512=, timeout 45 seconds, and no
retries: at most seven paid calls. Save raw response text and response IDs
outside the repository. The model must return one =(answer ...)= datum.
A native Scheme scorer reads the datum without evaluating it, rejects
unreadable answers, compares row-set fields independent of row order, and
compares status and diagnostic fields exactly.
Syntax validity and exact answer correctness are separate results.

The preview is generated with:

#+begin_src sh
python -m agentic_ai_lab_testing.model_study.scheme \
  --ascent-root /path/to/pinned/gerbil-ascent \
  --poo-root /path/to/agentic-ai-lab \
  --gerbil-path /path/to/agentic-ai-lab/.gerbil \
  --preview-dir /private/tmp/poo-scheme-module-preview
#+end_src
