#+TITLE: Trusted native original Derivation admission through fixed ABI v1

* Actual native owner path

Rust retains and re-admits original MRR Rules, Catalog, Facts and Derivations.
=typed-native-proof.ss= contains the exact inert original Rust request and the
actual native joint result. Python replays the same request/result without
creating owner records. The selected root path(1,3) uses intermediate path(1,2)
and edge(2,3) as direct MRR inputs. Temporal support binds the two transitive
source leaves to separately named Host subjects and revision IDs.

The dedicated C control =agentic_ai_lab_semantic_v1_derivation_admit= invokes the
original Scheme producer and positive-proof replay, Rule node correspondence,
selected original direct Derivation inputs and exact journal bindings. The
response projects proof/Rule/Derivation flags from those native admission
objects. No serialized proof, completion flag or node assignment is accepted.
Ordinary C calls to the control reject with status 3; Python/Rust reject the
ordinary operation before enqueueing. The descriptor does not list the control.

Source content, RuleId/direct support substitution, missing/duplicate/unused
facts, absent Derivation authority, source marker, schema, column type,
generation and work/node bound controls reject. Repeated valid admission remains
deterministic after rejection. Late correction invalidates current support;
the historical cut remains supported. The ordinary support evaluator retains
its conservative flags even when given a previously admitted support label.

* Remaining boundaries

This is bounded, positive, source-relative admission with one selected original
Derivation per derived fact. The control does not retain a current proof
registry, authenticate a provider, obtain authoritative current source/catalog/
clock state, combine proof and policy into a final effect fence, or publish Data
with CAS. Source authentication, selection, action and durability remain false.
No real model or benchmark ran. Production current-state/refinement and remote
CI qualification remain distinct outstanding gates.
