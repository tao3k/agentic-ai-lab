* Scope and inherited contracts

This connects the selected [[file:05-concurrent-evidence-lifecycle.org][SysML concurrent evidence lifecycle]] observations
to actual Scheme and ASCENT implementation calls. It follows the existing
[[file:../../../../core/module-system/design/context-temporal-lifecycle-policy-system-design.org][ASCENT-centered joint lifecycle contract]],
[[file:../../../../core/module-system/design/ai-agentic-context-session-memory-contracts.org][Session/Memory protocol contracts]] and the original native evaluator tests.
It is a native execution receipt for selected paths, not an automatic proof of
bisimulation for all 2,240 SysML interleavings.

Three added Cases in
[[file:../../../../t/temporal-evaluator-test.ss][temporal-evaluator-test.ss]] reuse its original-owner fixtures:

- =reasoning-attempt= runs the installed ASCENT path program over edges (1,2)
  and (2,3), producing path (1,3) with a complete positive-proof receipt.
- Native positive-proof admission, original Rule/Fact/Derivation correspondence
  and direct-premise support bind that real proof DAG to the journal.
- Registered proof Host/current support evaluation and serialized Context Host
  enrollment/revalidation operate on native POO values and real Host state.
- A real Scheme thread waits for a cancellation message, then returns the old
  Attempt. The owner actually joins it before proposing reconciliation.

The MRR Rule/Fact/Derivation files are inert original-owner projection fixtures;
no MRR server or producer was started. Fact/source correspondence is declared
and checked within those fixtures, not authenticated physical-world evidence.
The Context fixture explicitly does not establish Org-to-Fact authority
refinement. Actual proof replay is source-relative, not a proof that the input
sources are true or that an effect is authorized.

Current proof, grant/policy and Scope remain independent checks. A retained
=proof-admitted?= observation remains true after withdrawal while current
status becomes =unsupported=. Reading historical admission without current
applicability is precisely the unsafe bypass the model must reject.

Commitments identify these local values; they do not authenticate sources.

The retained native bypass counterexample is intentional and important:
=session-complete(old-schedule, old-revision, old-attempt)= still produces an
accepted *pure intent* after the proof owner has withdrawn a premise. Session
owns interaction identity, not the current Context proof registry. The native
Context owner rejects current consumption and revalidation moves the actual
active Attempt into recovery obligations. A caller cannot publish the old
intent merely because its local function returned accepted.

Thus the counterexample confirms the need for current-owner publication and
also identifies an unclosed implementation boundary. It is not represented as
an observed unauthorized provider effect or as an already fixed production CAS.
No new result-publication capability or fake terminal receipt was introduced.

* Remaining implementation and research obligations

The real proof/support/journal and Scheme-thread paths are now exercised; the
following remain open and must not be inferred from those passes:

1. Provider result receipt authentication, exact payload/producer admission and
   publication through a current-owner CAS or transaction.
2. Native cross-owner atomicity for simultaneous result/cancellation publication,
   durable outbox/restart, real external effect ambiguity and resource release.
3. Authenticated Org-to-Fact/premise mapping and complete reverse-dependency /
   absence coverage for general incremental invalidation.
4. Automatic replay of every saved SysML trace against one qualified native
   reducer. This run maps selected paths and exposes the missing P publication
   boundary; it is not full model-to-native refinement.
5. Task-quality/cost comparison with CLM or other memory systems. See the
   [[file:07-context-literature-comparison.org][primary-source literature comparison and controlled experiment design]].
