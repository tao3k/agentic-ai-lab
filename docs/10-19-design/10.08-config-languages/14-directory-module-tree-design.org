* Shared design ownership

Directory source Contracts, source-role structure, native lazy tree projection,
interface publication and generic selected build views are owned by the
[[file:../../../core/module-system/design/README.org][Core Module System design]] in the agentic-ai-lab-core submodule. The earlier generic
proposal here has been separated by ownership; do not evolve a second copy.

* Agentic AI Lab responsibilities

Agentic AI Lab owns yuanxu! syntax, default source/authoring policy, the existing
yuanxu-load-modules product facade and its integration with Core protocols,
product Feature System, JsonSchema bridge, contribution Profiles/Scenarios and
runtime/build providers. Those implementation owners are not moved by this work.

The [[file:../../../core/docs/10-19-design/11-configuration-languages/11.16-directory-contract-and-native-tree.org][JsonSchema/Guestbook consumer design]], [[file:../../../core/docs/10-19-design/11-configuration-languages/11.18-guestbook-auto-explicit-init-examples.org][complete init examples]] and
[[file:../../../core/docs/10-19-design/11-configuration-languages/11.19-feature-system-guestbook-selection.org][Module/Feature integration]] retain their product-specific code and controls.
Core must remain usable without importing those consumers.

* Evidence boundary

The shared directory adapter and end-to-end Guestbook renderer remain design.
No Core source, gitlink, Loader, build registration or runtime behavior is migrated.
