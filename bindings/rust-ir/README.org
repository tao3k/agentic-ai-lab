#+TITLE: Agentic AI Lab Scheme-owned Rust IR

This directory contains byte-stable build inputs projected from executable
Scheme contracts.  =gerbil-parser= admits the bounded pure Scheme subset and
emits versioned function IR; =gerbil-scheme-rust-ir= lowers that IR to typed
Rust during the consumer build.

The checked-in JSON is not a second contract and is never edited by hand.  Its
owning Scheme function and determinism test are:

- =modules/query/rust-ir.ss=
- =t/query-rust-ir-test.ss=

Native Rust consumers depend on the small =agentic-ai-lab-rust-ir= crate in this
directory.  The crate only embeds the checked-in IR as bytes; it contains no
contract implementation.  Consumer build scripts lower those bytes through
=gerbil-scheme-rust-ir=, so no checkout path or runtime Scheme process is
required.

The Query candidate projection performs transport pre-admission only.  It does
not execute a Query, manufacture an MRR receipt, or grant action authority.
