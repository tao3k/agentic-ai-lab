# Frozen branch-reuse experiment protocol

Plan SHA256: `9872c7108ab0f0c246b6e0929b485974ddb3aebd8ca9fee0297dcca1c92ac890`. Source head: `652934cd728d7edee32df020af75e9632dffc755`. The inherited AOT grader is unchanged; this receipt does not qualify the entire working tree or remote CI.

The formal artificial task uses fixed seed 220411, seven stages, five literal options per stage, two graph-path requirements per eligibility Fact, shared subpaths and cross-stage bonuses. The disjoint calibration uses seed 330419. Task and goal parameters were not selected using model outcomes.

All arms receive the same native-admitted non-optimal seed `[0, 5, 10, 15, 20, 25, 30]` for both goals. Goal 0 value/gap: 200/126; goal 1: 239/121. The baseline has no initial ASCENT packet, but the common feasible seed itself implies eligibility of its constituent fragments. It is therefore not an absolute evidence-free condition. Fresh and retained have byte-identical initial packets; private native state alone cannot establish a model-side cognitive effect.

Every solver response chooses exactly one unvisited child of a controller-scheduled parent. The native independent raw-source grader admits or rejects that prefix, independently evaluates a full candidate made by appending the common seed suffix, and keeps the best valid candidate. The controller uses depth-first scheduling and preserves the incumbent without requiring a final model response. No oracle optimum is supplied to the solver. Counterfactual arithmetic totals do not include eligibility. A chosen-branch validity result is supplied in the next local context.

Each local decision receives a new bounded context with immutable source, evidence (if supplied), current parent, unvisited children, common seed and incumbent. Earlier thinking is not replayed. This is an explicit external-memory search test, not a claim about arbitrary long-context workloads. Returned thinking is kept verbatim, including incomplete responses.

All input and all output count against 65,536 gross tokens per phase. Thinking is already a subset of output, and cached input is charged in full. A 3,072-token per-call cap bounds each local decision. Known-cost incomplete calls are failures and contribute no branch action; subsequent newly billed calls may try the same parent under the frozen policy. Unknown cost stops the phase. A conservative byte-based input/output reserve may leave unused budget, which is not called savings. Common-spend checkpoints at 16,384, 32,768 and 49,152 tokens use only completed expansions observed before each boundary. A phase that never reaches a checkpoint remains missing there.

The independent outcome grader uses original source edges and exhaustive native enumeration, never ASCENT proof receipts or model explanations. Annotation rules are frozen before calibration: exact returned-text spans, atomic path versus whole-conjunction identity, derive/reuse/mention/conditional-recheck/uncertain, matching ordered premises and native conclusion truth. Identical-premise repeated derivations, packet-covered rederivations and cross-goal matches are separate measures. A changed witness is not silently treated as an identical-premise repeat. Exact-span/native-truth validation does not establish complete semantic extraction or independent-rater agreement. The annotator uses the same provider with arm/outcome metadata withheld; reasoning content can reveal packet availability.

The reporting endpoint is a controller-selected incumbent, not a model submission. The common seed is not a model achievement. Full seeded-candidate length is not exploration depth; depth is the length of an executed native-admitted prefix. Every failed model call, invalid prefix, invalid completed candidate, annotation rejection and unused-budget stop remains in the raw ledger.

Network payload previews contain only the artificial graph, PRNG-generated numeric options and fixture proof nodes/hashes. No repository source, business documents or credentials are sent as model input. Destination is the same DeepSeek Responses endpoint as earlier rounds. The first automatic approval rejection and the subsequent payload-evidence review are recorded in the session; calibration began only after re-review allowed execution.
