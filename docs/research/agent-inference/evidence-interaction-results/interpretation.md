# Library consumer qualification and failed model effect test

The native Library/consumer semantic gate passed on three frozen tasks. The model study did not establish reduced repeated reasoning, greater exploration depth, or better result quality. ASCENT Scheme remains a Library; the search controller is a consumer fixture outside its build. Agentic AI Lab owns temporal projection and reevaluation planning. No MRR/Rust integration or new Lean/Quint proof is claimed.

At the common 32,768-token checkpoint (input plus all output, including thinking and failed calls):

| Task | Baseline value / depth | Fact evidence value / depth | Native pruning value / depth |
|---|---:|---:|---:|
| 0 | 189 / 2 | 189 / 2 | 189 / 2 |
| 1 | 220 / 2 | 190 / 1 | 190 / 1 |

Final values were 189 for all three task-0 arms and 220 for all three task-1 arms. All remained nonoptimal. The six arms made 31 calls; 19 were truncated and charged without admitting an action. Solver gross usage was 286,938 tokens. Each arm had the same 65,536 ceiling; conservative next-call reservation left unused budget. That unused allocation is not savings. Separate calibration and annotation charges are in the report.

The frozen repeat detector found no qualified exact-chain repeat in any arm. It accepted 27 labels, rejected 224, and had one missing annotation call. Same-provider extraction was not independently validated for coverage or category accuracy. A zero count therefore does not establish absence of repetition. In particular, the baseline did not produce a measurable repeat signal under this narrow rule, so a reduction cannot be demonstrated.

Post-hoc diagnostic review is separate from the frozen metric. The source-anchored quotes in `contract-observations.json` show the model questioning whether bonus triples name option IDs or fragment IDs. The native judge uses option IDs, while the ordinary input says only selected pairs. This interpretation work can confound attribution; it must not be counted as Fact derivation. The study is preserved without changing its task, judge, token ceiling, or prompts after freezing.

A subsequent model verification needs an explicit ordinary task-data schema for option IDs, goal-indexed values and bonus triples, plus a demonstrated baseline repeat signal and completed cross-path expansions. These are consumer test prerequisites, not Library workflow features or instructions to avoid thinking. The Library obligations remain relational correctness, scoped computational proof reuse, revision isolation and bounded/unknown behavior. Live revision during a model dialogue remains unqualified.
